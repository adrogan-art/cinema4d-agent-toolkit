# Cinema 4D Skills (public)

Public subset of Cinema 4D Python skills for Claude Code / Codex.

| Skill | Purpose |
|-------|---------|
| [`cinema4d-c4dpy`](cinema4d-c4dpy/) | Execute and verify Cinema 4D Python code headlessly with the matching `c4dpy.exe`. |
| [`cinema4d-gui-testing`](cinema4d-gui-testing/) | Run deterministic Cinema 4D Python integration tests that require the real Windows GUI and event loop. |
| [`develop-cinema4d-tools`](develop-cinema4d-tools/) | Design, implement, diagnose, and verify reusable Cinema 4D Python scripts and plugins (`.py` / `.pyp`). |

Each skill is a self-contained directory with a `SKILL.md` entry point. Drop a skill folder into your agent's skills directory to use it.
